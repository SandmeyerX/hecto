# hecto：在 Rust 语言中构建属于自己的文本编辑器

**教程：[hecto: Build Your Own Text Editor in Rust](https://philippflenker.com/hecto/)**

这是用 Rust 语言对 [antirez 的 kilo](http://antirez.com/news/108) 的重新实现，同时也融合借鉴了 [Paige Ruten 针对该编辑器的 C 语言教程](https://viewsourcecode.org/snaptoken/kilo/index.html)。该项目由若干个文件构成，代码量大约 3000 行 Rust 代码，引入了少量依赖库；实现了极简编辑器该具备的全部基础功能，支持语法高亮与搜索功能。
